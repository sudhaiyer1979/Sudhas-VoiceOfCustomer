# WS8 - Voice of Customer Brand Analyzer

1. Install dependencies:

```
python -m pip install -r requirements-ws8.txt
```

2. Set your API key (Windows PowerShell):

```
$env:OPENAI_API_KEY="YOUR_KEY_HERE"
```

DO NOT put the key into GitHub.

3. Start the application:

```
python app.py
```

4. Open:

```
http://127.0.0.1:5000
```
